# JavaScript Calculator

A browser-based calculator built with HTML, CSS, and vanilla JavaScript.

## Overview

This project explores the fundamentals of building an interactive web application by combining JavaScript logic with DOM manipulation. Rather than relying on built-in calculator functionality, the application manages its own state, processes user input, and updates the interface in response to user interactions.

## Concepts Explored

* JavaScript fundamentals
* DOM manipulation
* Event listeners
* State management
* Conditional logic
* Arithmetic operations
* User input handling
* Responsive interface design

## Features

* Addition, subtraction, multiplication, and division
* Clear/reset functionality
* Real-time display updates
* Responsive button interactions
* Clean and intuitive user interface

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## What I Learned

Through this project I gained experience with:

* Structuring JavaScript into state variables, cached elements, event listeners, and functions.
* Managing application state throughout user interactions.
* Updating the DOM dynamically in response to events.
* Breaking complex logic into reusable functions.
* Debugging JavaScript using browser developer tools.
* Building an interactive application from scratch using vanilla JavaScript.
